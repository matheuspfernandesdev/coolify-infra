# coolify-infra

## Visão Geral

Projeto de infraestrutura com foco em **observabilidade** e, simultaneamente, na exploração da ferramenta **Coolify**.

Já existe, na mesma pasta de trabalho, um projeto chamado **VPS Infra**, utilizado para provisionar recursos como Nginx, Let's Encrypt / Certbot, MinIO e outros recursos de infraestrutura.

Neste novo projeto, o objetivo é testar o Coolify como ferramenta de gerenciamento e deploy da infraestrutura de observabilidade.

## Objetivo

Servir tanto para estudar observabilidade quanto para avaliar, na prática, as capacidades do Coolify para esse tipo de infraestrutura.

## Stack Inicial de Observabilidade

- Node Exporter.
- Grafana.
- Prometheus.
- Outras ferramentas relevantes de observabilidade.

## Status

Projeto recém-criado. Documentação de ideação (IDM) inicial. Implementação ainda não iniciada.
